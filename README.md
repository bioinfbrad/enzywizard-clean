# Command: enzywizard-clean


EnzyWizard-Clean is a command-line tool for cleaning protein structures, generating 
multi-format protein files (CIF, PDB, and FASTA), and providing a detailed traceable
JSON report that records residue mapping between the original and cleaned 
protein structures. Using PDBFixer APIs, it removes heterogens, repairs missing
heavy atoms, optionally adds hydrogens, and converts the structure 
into a continuous protein chain with standardized residue numbering.
The tool outputs cleaned structure files together with a JSON report summarizing 
residue mapping and clean statistics.

# example usage:

The examples below use placeholder paths such as `path/to/input.cif` and
`path/to/output_dir/`; replace them with your own input structure file and
output directory.

Clean a CIF file with default settings. Hydrogens are added at pH 7.0 by default.

```
enzywizard-clean -i path/to/input.cif -o path/to/output_dir/
```

Clean a PDB file with default settings.

```
enzywizard-clean -i path/to/input.pdb -o path/to/output_dir/
```

Clean a structure without adding hydrogens.

```
enzywizard-clean -i path/to/input.cif -o path/to/output_dir/ --no_add_H
```

Clean a structure and add hydrogens using a specified pH.

```
enzywizard-clean -i path/to/input.cif -o path/to/output_dir/ --pH 7.5
```



# input parameters:

-i, --input_path
Required.
Path to the input protein structure file.
Supported file extensions: .cif, .pdb.

-o, --output_dir
Required.
Path to the output directory for saving cleaned structure files and the JSON report.
The output directory is created automatically if it does not exist.

--no_add_H
Optional flag.
Disable hydrogen addition using OpenMM.
By default, hydrogens are added.
Omit this flag to add hydrogens.

--pH
Optional.
pH value used for hydrogen addition.
This option is only used when hydrogen addition is enabled.
Default: 7.0
Valid range: 0.0 to 14.0


# output files:

The program outputs the following files into the output directory:

`{name}` is derived from the input file name without its extension.

1. Cleaned structure files
   - cleaned_{name}.cif
     - Cleaned protein structure in CIF format.
   - cleaned_{name}.pdb
     - Cleaned protein structure in PDB format.
   - cleaned_{name}.fasta
     - Cleaned amino acid sequence in FASTA format.

2. A JSON report
   - clean_report_{name}.json
     - JSON report containing residue mapping and cleaning statistics.

3. A log file
   - log.txt
     - Processing log containing informational messages and errors.


# output report schema:

The JSON report contains the following fields:

   - "report_type"
     - Data type: string
     - Expected value: "enzywizard_clean"
     - Description: The field "report_type" indicates the type of report generated by the EnzyWizard-Clean software.

   - "residue_mapping_old_to_new"
     - Data type: array
     - Description: The field "residue_mapping_old_to_new" indicates the mapping of residues ("residue": http://purl.obolibrary.org/obo/GENO_0000782) derived from the original protein structure ("protein structure": http://edamontology.org/data_1537) to the cleaned protein structure.

     Each item in "residue_mapping_old_to_new" is an object containing:

     - "old_residue"
       - Data type: object
       - Description: The field "old_residue" indicates the residue ("residue": http://purl.obolibrary.org/obo/GENO_0000782) in the original protein structure ("protein structure": http://edamontology.org/data_1537).

       The "old_residue" object contains:

       - "residue_index"
         - Data type: integer
         - Description: The field "residue_index" indicates the index ("index": http://purl.obolibrary.org/obo/NCIT_C25390) of residues ("residue": http://purl.obolibrary.org/obo/GENO_0000782).

       - "residue_name"
         - Data type: string
         - Allowed values: A, C, D, E, F, G, H, I, K, L, M, N, P, Q, R, S, T, V, W, Y.
         - Description: The field "residue_name" indicates the name of residues ("residue": http://purl.obolibrary.org/obo/GENO_0000782), using one-letter codes ("one-letter code": https://iupac.qmul.ac.uk/AminoAcid/A2021.html) to represent.

       - "hydrogen_atom_count"
         - Data type: integer
         - Description: The field "hydrogen_atom_count" indicates the count of hydrogen atoms ("hydrogen": http://purl.obolibrary.org/obo/CHEBI_18276; "atom": http://purl.obolibrary.org/obo/CHMO_0001075) in the residue ("residue": http://purl.obolibrary.org/obo/GENO_0000782).

     - "new_residue"
       - Data type: object
       - Description: The field "new_residue" indicates the residue ("residue": http://purl.obolibrary.org/obo/GENO_0000782) in the cleaned protein structure ("protein structure": http://edamontology.org/data_1537).

       The "new_residue" object contains:

       - "residue_index"
         - Data type: integer
         - Description: The field "residue_index" indicates the index ("index": http://purl.obolibrary.org/obo/NCIT_C25390) of residues ("residue": http://purl.obolibrary.org/obo/GENO_0000782).

       - "residue_name"
         - Data type: string
         - Allowed values: A, C, D, E, F, G, H, I, K, L, M, N, P, Q, R, S, T, V, W, Y.
         - Description: The field "residue_name" indicates the name of residues ("residue": http://purl.obolibrary.org/obo/GENO_0000782), using one-letter code ("one-letter code": https://iupac.qmul.ac.uk/AminoAcid/A2021.html) to represent.

       - "hydrogen_atom_count"
         - Data type: integer
         - Description: The field "hydrogen_atom_count" indicates the count of hydrogen ("hydrogen": http://purl.obolibrary.org/obo/CHEBI_18276) atoms ("atom": http://purl.obolibrary.org/obo/CHMO_0001075) in the residue ("residue": http://purl.obolibrary.org/obo/GENO_0000782).

   - "clean_statistics"
     - Data type: object
     - Description: The field "clean_statistics" indicates the summary cleaning statistics ("statistics": http://purl.obolibrary.org/obo/STATO_0000039).

     The "clean_statistics" object contains:

     - "removed_heterogen_count"
       - Data type: integer
       - Description: The field "removed_heterogen_count" indicates the count of removed heterogens ("heterogen": https://www.wwpdb.org/documentation/file-format-content/format33/sect9.html).

     - "standardized_residue_name_count"
       - Data type: integer
       - Description: The field "standardized_residue_name_count" indicates the count of standardized residue names ("residue": http://purl.obolibrary.org/obo/GENO_0000782).

     - "repaired_residue_count"
       - Data type: integer
       - Description: The field "repaired_residue_count" indicates the count of repaired residues ("residue": http://purl.obolibrary.org/obo/GENO_0000782).

     - "added_heavy_atom_count"
       - Data type: integer
       - Description: The field "added_heavy_atom_count" indicates the count of added heavy atoms ("heavy atom": https://goldbook.iupac.org/terms/view/H02899).

     - "added_hydrogen_atom_count"
       - Data type: integer
       - Description: The field "added_hydrogen_atom_count" indicates the count of added hydrogen atoms ("hydrogen": http://purl.obolibrary.org/obo/CHEBI_18276; "atom": http://purl.obolibrary.org/obo/CHMO_0001075).

     - "retained_residue_count"
       - Data type: integer
       - Description: The field "retained_residue_count" indicates the count of retained residues ("residue": http://purl.obolibrary.org/obo/GENO_0000782).

# Process:

This command processes the input protein structure as follows:

1. Load the input structure
   - Read the CIF or PDB file using PDBFixer.
   - Resolve the protein name from the input filename.

2. Validate basic input conditions
   - Check that the input file exists.
   - Check that the pH value is within the valid range.

3. Clean the structure (PDBFixer-based processing)
   - Keep only the first chain.
   - Identify non-standard residues.
   - Remove all heterogens, including water and ligands.
   - Replace non-standard residues with standard residues.
   - Disable missing residue reconstruction; do not add missing residues.
   - Detect missing atoms.
   - Add missing heavy atoms.
   - Optionally add hydrogens using OpenMM ForceField with specified pH.
   - Check for invalid coordinates, such as NaN values.

4. Renumber the structure
   - Rebuild the topology to ensure:
     - single chain with chain ID A,
     - continuous residue numbering starting from 1.

5. Validate the cleaned structure
   - Ensure single model and single chain.
   - Ensure no hetero residues remain.
   - Ensure residue names are standardized.
   - Ensure residue numbering is continuous.
   - Ensure all required backbone and heavy atoms are present.

6. Save outputs
   - Save the cleaned structure in CIF format.
   - Save the cleaned structure in PDB format.
   - Extract and save the cleaned amino acid sequence in FASTA format.
   - Generate and save the JSON report summarizing residue mapping and clean statistics.


# common errors and solutions:

- "Invalid pH value"
  - Cause: The value passed to `--pH` is outside the valid range.
  - Solution: Use a numeric pH value from 0.0 to 14.0.

- "Input not found"
  - Cause: The path passed to `-i` or `--input_path` does not exist or is not a file.
  - Solution: Check the input file path and make sure it points to an existing CIF or PDB file.

- "Filename too long"
  - Cause: The input file name without extension is longer than the supported filename limit.
  - Solution: Rename the input file to a shorter name and run the command again.

- "File is empty"
  - Cause: The input file exists but has no content.
  - Solution: Use a valid non-empty protein structure file.

- "Unsupported format"
  - Cause: The input file extension is not `.cif` or `.pdb`.
  - Solution: Use a supported structure file format.

- "Exception in addMissingHydrogens"
  - Cause: OpenMM failed while adding hydrogens, often because of force-field, residue, or structure issues.
  - Solution: Check the structure quality, adjust the pH value, or run with `--no_add_H`.

- "NaN coordinates detected after PDBFixer cleaning"
  - Cause: The cleaned structure contains invalid coordinates.
  - Solution: Check the input structure for invalid coordinates or severe structural problems.

- Failed to load PDBFixer, no topology found, or no chain found
  - Cause: The input file could not be parsed as a usable protein structure.
  - Solution: Check that the file is valid, non-corrupted, and contains at least one protein chain.

- Cleaned structure validation failed
  - Cause: The cleaned structure still contains unsupported residues, heterogens, insertion codes, non-continuous numbering, missing atoms, or unexpected atoms.
  - Solution: Check the input structure quality and review earlier messages in `log.txt`.

- Mapping or report generation failed
  - Cause: The residue mapping does not match the original or cleaned structure, or the report could not be built.
  - Solution: Check whether the input contains unusual chains, residues, or records that cannot be mapped cleanly.

- Failed to load original or cleaned structure
  - Cause: The original input file or the cleaned CIF file could not be parsed while preparing validation or the JSON report.
  - Solution: Check `log.txt`, confirm that the input structure is valid, and confirm that the cleaned output was written correctly.

- Output files are missing
  - Cause: The command failed before all output files were written, or the output directory is not the one expected.
  - Solution: Check `log.txt`, confirm the `-o` output directory, and rerun after fixing earlier errors.

- Output file names are different from expected
  - Cause: Output names use `{name}`, which is derived from the input file name without its extension.
  - Solution: Check the input file name and look for files named `cleaned_{name}.cif`, `cleaned_{name}.pdb`, `cleaned_{name}.fasta`, and `clean_report_{name}.json`.
